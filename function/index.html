    \brief Generic 1D spline evaluations \details Evaluate f(x) at given x By default, spline starts from x=0,y=0, and get up to x=(nx-1)*delx, out of bound x values are not checked, and the function is evaluated using the last cell spline coefficients.

    Comment Block

    Boundary condition needs to be provided by programmer BC 0: use spline0 BC 1: use spline1 BC 2: use spline_periodic \sa construct_spline1d

    Comment Block

    @param[in] x evaluation location

    Comment Block

    @param[in] deriv derivative order: 0 for f(x), 1 for f'(x)

    Comment Block

    @param[in] nx total number of grids in spline mesh

    Comment Block

    @param[in] delx spline grid step size

    Comment Block

    @param[in] y spline coefficients array

    Comment Block

    @param[in] bcx Boundary condition - 0: normal spline with calculated 1st derivative - 1: special 1st cell square root spline - 2: periodic boundary condition

    Comment Block

    normal 1D spline evaluator

    Comment Block

    \brief Generic 2D spline function \details Evaluate f(x,y) or its partial derivatives using the created spline coefficients for f By default, spline starts from x=0,y=0, and get up to x=(nx-1)delx, and y=(ny-1)dely. Out of range (x,y) are not checked

    Comment Block
