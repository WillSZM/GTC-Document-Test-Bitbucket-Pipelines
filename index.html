    Introduction

    The Gyrokinetic Toroidal Code (GTC) is a particle-in-cell simulation of plasma instabilities and turbulence in fusion devices.

    Website

    http://phoenix.ps.uci.edu/gtc/

    Notes to Developers

    Work Flow

    Starting with GTC v4.0, the workflow structure is such the Public and Master branches are solely write-able only to Dr. Zhihong Lin and administrators of this repository. GTC users should pull from the Master branch for simulations. GTC developers should pull from the Update branch for developments.

    • public -- (v4.0) Public release version, available for public usage.
    • master -- (v4.X) Stable and tested team release version, available upon request for collaborating GTC users.
    • dev -- Physics related feature development branch. Developers should branch from and merge into this branch when work on a new feature.
    • gpu -- GPU acceleraion related feature development branch. Aimed to optimize each "update" version.

    File Tree

    Source Files

    All the source files, including the Makefile, should be located in the src/ folder.

    Generic Input Files

    A generic gtc.in file is maintained in input/ folder. This file should be updated if new input parameters are added.

    Input data files are not required to be included in the Git repository if its too large. A link to the path on the phoenix server is strongly encouraged.

    New input data file name convention needs to be added into the input/DataFileFormat.md file.

    Specific Test Cases

    Specific Test Cases are provided in TestCases/[casename] folder. A corresponding gtc.in should be provided, with a short description of the case under study.

    Input data files are not to be included in the Git repository, but stored on GTC phoenix server. A file containing the path to the data files is required.

    Benchmark Record Files

    Extensive benchmarks are done for every master level release. The full records are stored on the phoenix server. The input files for each benchmark case are located in the benchmarkInputFiles/ folder, under the corresponding version numbered folders.

    Platform Dependent Scripts

    Job submission helper scripts are located in the jobFiles/ folder. Modifications may be needed.

    Documentation and Supplimentary Materials

    Developer or User oriented documentations are located in Doc/ folder.

    Get started with Git

    An introduction to the basic Git operations is provided here. BitBucket has a more detailed introduction that is highly recommanded for first time users of Git or BitBucket.
